# Orbit Rush

A one-tap orbit arcade game. The whole game is `www/index.html`: plain HTML, CSS and JS with no build step. It's wrapped as an Android app with Capacitor 7.

- **Web build:** drop the `www/` folder on Netlify. Ads, purchases and the privacy button hide themselves in a browser.
- **Android app:** the `android/` folder, generated by Capacitor.

All tuning values live in the `CONFIG` block at the top of the script in `www/index.html`. The `JUICE_*` values control feedback intensity only. Difficulty and scoring use the other values.

## Languages

The game ships in English, Spanish, Portuguese (Brazil), Indonesian and Filipino.

- Every word the player sees lives in the `STR` table in `www/index.html`, one block per language. New text must go through `tr("key")` with a matching key in each block. A key missing from a language falls back to English, so nothing ever shows blank.
- The language comes from, in order: a `?lang=` link (the ETS site always adds one), the player's choice from the 🌐 button on the home screen, the device language, then English. Codes match case-insensitively (`pt-br` works).
- To add a language: copy the `en` block, translate it, and add the code to `Lang.LIST` and `Lang.NAMES`. Then add it to `android/app/src/main/res/xml/locales_config.xml`, `resourceConfigurations` in `android/app/build.gradle`, and a folder under `fastlane/metadata/android/`.
- Store listing text for each Play language is in `fastlane/metadata/android/<locale>/` (title, short and full description). Paste it into Play Console under Store presence → Main store listing → Manage translations, or upload it with fastlane `supply`.

## One-time setup on your PC

1. Install [Node.js LTS](https://nodejs.org) and [Android Studio](https://developer.android.com/studio). The first time Android Studio opens, let it install the Android SDK, including **API 36**.
2. In this folder, run:
   ```
   npm install
   npx cap sync android
   ```
3. Create the upload key once and keep it backed up. If you lose it, you have to ask Google to reset your upload key.
   ```
   keytool -genkeypair -v -keystore android/orbit-rush-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
   ```
   Copy `android/keystore.properties.example` to `android/keystore.properties` and fill in the passwords. Git ignores both files.

## Before the first release

1. **AdMob:** create the app and its 3 ad units (banner, interstitial, rewarded) in AdMob. Then run:
   ```
   node scripts/set-ad-ids.js --app ca-app-pub-…~… --banner ca-app-pub-…/… --interstitial ca-app-pub-…/… --rewarded ca-app-pub-…/…
   ```
   This replaces the test IDs in `www/index.html`, `capacitor.config.json` and `AndroidManifest.xml`, and turns off test mode.
2. **In-app products:** in Play Console, go to Monetize → In-app products and create the 4 coin packs and Remove Ads. Then copy their product IDs into `CONFIG.IAP_COIN_PACKS` and `CONFIG.IAP_REMOVE_ADS_PRODUCT_ID`. The current IDs are placeholders.
3. **App ID:** the package is `com.etsholdings.orbitrush`. Once you upload it to Play, it can never change, so change it first if you want something different. It's set in `capacitor.config.json` and in `android/app/build.gradle` as `namespace` and `applicationId`.
4. **Icon:** the launcher icon is still the default Capacitor one. In Android Studio, use right-click `res` → New → Image Asset.
5. Bump `versionCode` in `android/app/build.gradle` on every upload.

## Build the release bundle

```
npx cap sync android
cd android && ./gradlew bundleRelease      (Windows: gradlew.bat bundleRelease)
```
The output is `android/app/build/outputs/bundle/release/app-release.aab`. Upload it in Play Console.

## Play Console checklist

- Data safety: declare the advertising ID, plus the device and app info that AdMob collects.
- Ads: answer "Yes, contains ads".
- Privacy policy URL: required because the app shows ads.
- Content rating questionnaire, target audience, and store listing: icon, feature graphic, screenshots.
