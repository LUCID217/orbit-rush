# Reports

One file per run: `YYYY-MM-DD-NNN-short-name.md` (matching the brief). Eugene reads these in the morning, so keep each one short:

1. **Done:** what changed, with the commit hash.
2. **Blocked:** anything that failed twice, and why.
3. **Needs Eugene:** decisions only he can make (one-way doors, big blast radius, anything to publish, send, spend or delete).

`NOTES.md` stays the project's living state (what's built, interpretations, balance, known bugs). Update it as well, but the report is what Eugene reads first.
